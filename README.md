## About

My personal LeetCode solutions, written in Python. The goal is to practice problem solving, build consistency and keep a record of how my approaches evolve over time.

Each problem has its own folder with the solution and, when useful, notes about the approach and complexity.

## Summary

Every solved problem is listed in the summary files:

- [Easy](problems/easy.md)
- [Medium](problems/medium.md)
- [Hard](problems/hard.md)

## Repository Structure

```
leetcode-solutions/
├── assets/
│   └── leetcode-solutions-banner.png
├── problems/
│   ├── solutions/
│   │   └── 0001-two-sum/
│   │       └── solution.py
│   ├── easy.md
│   ├── medium.md
│   ├── hard.md
│   └── summary.md
├── .gitignore
├── LICENSE
├── README.md
└── README-PT.md
```

Folder names follow the pattern `NNNN-problem-name` (the LeetCode problem number with four digits, then the title in lowercase with hyphens).

### What each problem folder contains

- `solution.py`: the solution in Python. The top of the file has a short comment with the idea and the time/space complexity.
